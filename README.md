# Salvador Dalí

A dark Omarchy theme. Each picture sits centered on a 16:9 canvas with black bars, so the photograph or the artwork stays whole. The desktop is warm lampblack, with a melting-clock gold accent and a cold sky-blue complement.

The wallpapers are photographs of Salvador Dalí and photographs of his work: paintings, objects, and sculptures. Famous canvases such as The Persistence of Memory are not here. The Gala-Salvador Dalí Foundation has not released those files for download, and they stay in copyright until 2059.

Dalí died in 1989. Photographs of the paintings are still reproductions of his work. Rights are managed by the Fundació Gala-Salvador Dalí and VEGAP. This theme is for personal use on this machine. Do not publish it, or the pictures in it, without permission from the rights holders. The public-domain photographs (Halsman, Van Vechten, Library of Congress, Dutch National Archives) are the ones that can travel. Carl Van Vechten's estate asked that his portraits not be cropped or colorized, so those sit padded, not cropped.

Sources are Wikimedia Commons. Each file in backgrounds/ keeps the name of what it is. The opener is the melting clock.

This folder is not a git repo, and it should not be published while the paintings are in it.

Apply the local copy:

```bash
omarchy theme set "Salvador Dali"
```
